## Вставка 2 — Как работает (схема слева направо)
```
 Громкая связь ──► Распознавание речи ──► Модель ──► Шкала 0–100 + фразы + совет
   (рядом с устройством)  KK + RU (GigaAM; Vosk — живые слова)  (на устройстве)  │
                                                               ▼  только с согласия
                                                     Отчёт ──► Кабинет аналитика
                                                                (номера — хеш, текст — без ПДн)
```
**Сказать:** «Всё до отчёта происходит **на устройстве**, и после первого открытия работает даже без интернета. Звук не уходит никуда. Решение — всегда за человеком: мы не кладём трубку и ничего не блокируем.»

## Вставка 3 — Цифры доверия (4 карточки, зелёные)
| Крупно | Подпись |
|---|---|
| **1 из 19** | легитимных звонков вызывает тревогу (22 из 417 звонков, написанных **чужим** ИИ, которого модель никогда не видела) |
| **почти каждый второй** | мошеннический звонок от чужого ИИ пойман (187 из 411); на русском 56 %, на казахском 38 % |
| **3-я фраза** | на ней обычно срабатывает предупреждение — пока звонок идёт |
| **0 байт** | звука уходит с устройства |

Дополнительно, если есть место (мелко):
- **≈ 93 %** слов распознаётся верно — казахский и русский ⚠️ начитанная речь, не настоящий звонок
- **≈ 4×** быстрее реального времени распознаёт речь; фраза оценивается **быстрее секунды** (ноутбук) ⚠️ на настоящем телефоне не измерялось
- **200 / 200** звонков: браузер решает так же, как эталонная модель
- **более 2 000** автотестов; **7** правил приватности закреплены тестами
- На звонках того же генератора, что в обучении: 0 ложных тревог на 158 легитимных, 89–100 % пойманных ⚠️ завышено: генератор общий

**Сказать:** «Главная метрика для нас — **ложные тревоги**: если приложение пугает на звонке из настоящего банка, ему перестают верить. Мы проверяем себя на звонках, которые написал *чужой* ИИ, и показываем честную цифру — даже когда она хуже красивой.»

## Вставка 4 — Уникальность (таблица «мы / обычно»)
| | Обычные решения | **Qorğan** |
|---|---|---|
| Когда помогает | до звонка (блок номера) или после (заявление) | **во время разговора** |
| Где анализ | в облаке оператора / банка | **на устройстве**, звук не уходит |
| Языки | русский или английский | **казахский, русский и смешанная речь** |
| Объяснение | «подозрительно» | **точные фразы звонящего + что делать** |
| Кто решает | система блокирует | **человек**; ИИ только подсказывает |
| Приватность | обещание в политике | **проверяется автотестами** |

**Сказать:** «Мы не угадываем номер — мы узнаём **приёмы**: срочность, "никому не говорите", код из SMS, "безопасный счёт". Новый номер мошенника это не обходит.»

## Вставка 5 — Кабинет аналитика (скриншот admin + 3 факта)
- Отчёты граждан **группируются в организации** по общим номерам: на тестовой выборке **6 из 6** групп найдены без ошибок ⚠️ синтетика.
- **Новая схема** выделяется автоматически (пример в демо: «раздача криптовалюты»).
- Номера хранятся только как **хеш**; полный текст звонка открывает только следователь с указанием цели — **каждое открытие в журнале с HMAC-цепочкой**: правка или удаление строки видны при проверке. ⚠️ На демо роль следователя открыта всем, данные выдуманы.

**Финал (≈10 с):** «Следующий шаг — реальные записи звонков от банков и Антифрод-центра для проверки на живых данных. Модель, данные и код уже готовы к этому.»

## Запасные ответы на вопросы жюри (не на слайд)
| Вопрос | Ответ |
|---|---|
| Это на реальных звонках? | Нет, пока синтетические и написанные вручную. Протокол приёма реальных данных готов — это следующий шаг. |
| А если сценарий новый? | На 828 звонках, написанных **другим** ИИ, модель на устройстве ловит 45 %. Облачная проверка (только по желанию пользователя) на другом наборе — **33 из 33** при 0 ложных. |
| Работает на телефоне? | Сайт работает. На компьютере — полный голосовой режим; на телефоне включён облегчённый (только GigaAM), но на настоящем телефоне он ещё не запускался. На замедленном компьютере строка появляется примерно через 5 с, памяти нужно около 2,1 ГБ. |
| А без интернета? | После первого открытия проверка работает без сети: проверено с выключенным сервером и перезапущенным браузером, ответ тот же. |
| Английский? | Интерфейс и советы — да. Как язык звонка убран по решению стейкхолдеров: Qorğan — система для Казахстана, казахский и русский (ADR D70). |
| Почему ловите меньше половины? | Это честная цифра на звонках чужого ИИ. Наши переобучения поднимали её до 62 %, но начинали тревожить на семейных просьбах о деньгах. Мы заранее записали правило «на семейном звонке — никогда» и не выпускаем модель, которая его нарушает. |
| Что с законом? | Сделан разбор по закону о ПДн и закону об ИИ РК: система — низкой автономности, решение за человеком. |

## Чего не говорить
- «100 % точность» / «работает на любом телефоне» / «проверено на реальных звонках».
- Миллисекунды, FPR, WER, ARI — жюри их не считывает.
