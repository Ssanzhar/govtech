# Демо: что сделать перед показом и что показывать

_Для того, кто показывает. Числа и формулировки для питча: `docs/PITCH_2MIN.md`._

## Накануне

1. **Задеплоить** не позже чем за сутки и не раньше чем за 7 дней до показа. Без тома на Railway
   каждый деплой заново создаёт демо-данные: сервер отвечает через ~20 с, но кабинет аналитика
   наполняется ещё несколько минут (ADR D60). Если данным больше 7 дней, в кабинете будет «0 за эту неделю».
2. **Проверить деплой** из той же версии кода, только чтение, ничего не меняет:
   ```bash
   python scripts/preflight.py --base https://govtech-production.up.railway.app
   ```
   Должно быть `0 failed`. `WARN` про свежесть данных значит: нужен новый деплой.
3. **На компьютере для показа** один раз открыть `live.html`, запустить пример и включить микрофон
   (звук в браузер, модели на диск: ~650 МБ). После этого страница работает без интернета.
   Обновление `sw.js` модели больше не удаляет (ADR D86), но открыть один раз после последнего деплоя всё равно нужно.

## Показ (2 минуты)

| Шаг | Где | Что происходит |
|---|---|---|
| 1 | `live.html` → «Мошенник из банка» → «Начать проверку» | Шкала растёт до 98, появляются фразы и совет |
| 2 | Там же → «Настоящий звонок из банка» | Шкала остаётся низкой (26): ложной тревоги нет |
| 3 | Переключить язык на ҚАЗ посреди проверки | Всё на экране переходит на казахский, проверка продолжается |
| 4 | Итог → «Посмотреть сообщение» → номер `+7 700 101 20 30` → согласие → «Отправить» | Видно, что именно сохранено: номер только как `+7 700 ***`, квитанция |
| 5 | `admin.html` → «принять сообщения в анализ» | Сообщение попадает в организацию этого номера |
| 6 | Там же → фильтр «новые схемы» | Новая схема помечена сама (пример: раздача криптовалюты) |
| 7 | Открыть звонок → цель → «Открыть расшифровку» | Полный текст только с указанной целью, и это записано в журнал |

## Если что-то пошло не так

| Что случилось | Что делать |
|---|---|
| Нет интернета | Страница уже открывалась на этом компьютере: `live.html` работает без сети, пример считается так же. Кабинету аналитика сервер нужен. |
| Сервер упал или кабинет пуст | Запасное видео: `node tests_js/tools/record_demo_video.mjs` (записать заранее, папка `demo_video/`). Локальный запуск: `python -m qorgan.api`. |
| Микрофон не слышит | Показывать пример. Микрофон не обязателен для питча; в зале Vosk может склеить две фразы, это не ошибка. |
| Спросили про телефон | На настоящем телефоне голосовой режим ещё не запускался. Так и сказать (`docs/PITCH_2MIN.md`). |

## Чего не делать

- Не деплоить за 15 минут до показа: кабинет будет пустым, пока идёт заполнение.
- Не говорить «100 %», «работает на любом телефоне», «проверено на реальных звонках».
