How it works

Signal in, verdict out.

01

Listen

Feed it a call, a clip, a stream. 16 kHz mono is enough — no transcript, no cloud round-trip.

02

Measure

Formant drift, breath and pause markers, high-frequency energy, prosody flatness — the traces synthesis leaves in a signal.

03

Decide

A calibrated probability against an explicit threshold. Every verdict ships with the measurements that produced it.

Evidence

A verdict you can argue with.

Scores that can’t explain themselves get ignored — or worse, trusted blindly. saq returns the evidence with every call: which features moved the needle and by how much, so a reviewing human can agree — or push back.

The features are physical, not statistical folklore: things a phonetician could point to on the spectrogram.

Evaluation

False positives, reported first.

A detector that cries wolf gets switched off. saq is tuned FPR-first and evaluated on held-out real recordings — reported separately from synthetic test data, always.
